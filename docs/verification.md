## 公开内容检查

- 只分发本地集成代码、固定接口字段契约和合成测试数据。
- 生产账号、Cookie、token、数据库、私有素材、内部服务地址、团队配置和真实任务回执均不随包发布。
- `acceptance_records.json` 初始为空；功能目录不继承历史“已验证”状态。
- 官方 CLI 二进制不进入 Git、wheel 或源码包。安装时从官方分发源下载并核对固定 SHA-256。
- Python 运行时仅使用标准库，第三方运行依赖列表为空；构建工具为 setuptools。

## 平台和真实调用边界

[GitHub Actions 模板](github-actions-example.yml)包含 macOS / Ubuntu 与 Python 3.12 / 3.13 四个组合的离线测试和构建。本次发布账号的 OAuth 授权不含 `workflow` 范围，因此仓库未启用 Actions。需要拥有工作流写权限的维护者将模板放入 `.github/workflows/test.yml` 后再查看具体运行结果；模板存在不代表跨平台运行通过。

WSL2 为支持目标，尚未做真实 Windows / WSL2 环境验收。原生 Windows 会在加载 POSIX 模块前给出提示。

本轮未替新用户完成官方网页登录、OAuth 授权或付费媒体生成；没有逐项对新账号执行 122 个动作。个人主体、工作室接口和模型可用性还取决于该用户的独立认证、权限及官方接口版本。

视频延长的服务器实际生成、分享图片读取和目录中 16 项未接通功能仍有明确边界，参见 [README](../README.md#功能边界)。不能用 schema、dry-run、单元测试通过或 `COMPLETED` 状态替代媒体终态与文件验收。
