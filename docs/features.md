# 能做什么，接下来做什么

即梦 MCP 目前提供 122 项业务动作，统一放在 10 个 MCP 工具后面。Agent 先查询动作和参数，再提交任务。

## 已接入的方向

| 方向 | 可以用来做什么 |
| --- | --- |
| 画布 | 查询项目与节点、组织素材、调用画布创作能力 |
| 图片、视频、音频 | 准备生成参数、提交支持的创作任务、查询结果 |
| 官方创作 CLI | 管理创作会话、查询任务历史、调用多关键帧等能力 |
| 主体与声音 | 管理已支持的主体信息和已有声音绑定 |
| 短剧工作室 | 操作已接入的剧本、分集、故事板及相关素材 |
| 素材与任务 | 排队、保存记录、回查进度、下载并导出受管素材 |

画布、创作 CLI 和网页工作室各有对应的登录入口，见 [登录指南](authentication.md)。可用模型、权限和积分随账号而定。

## 几项功能的当前用法

- **主体创建**：目前通过已有图片主体复制创建；文字信息可以更新，参考图重组还待补充。
- **个人声音**：支持已有声音的绑定、替换和解绑，新音色生成待开发。
- **删除**：主体和分集支持永久删除，执行前确认具体对象；可恢复归档待补充。
- **分享图片读取**：接口已加入，成功读取的运行验证还待完成。
- **视频延长**：需要网页中已经保存的原生目标草稿。自动创建目标草稿、经本服务实际生成延长视频，还在后续验证范围内。

网页接口会随官方更新变化。发现某个动作报错时，提供动作名称、版本和错误码，方便定位。

安装、离线测试和真实生成分别记录在 [验证记录](verification.md)中。
